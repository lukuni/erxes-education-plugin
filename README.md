# Education: Монгол бичиг ба цээж бичиг

Монгол хэлний зөв бичгийн бодит мэдлэгийг хөгжүүлдэг нээлттэй эхийн [erxes](https://erxes.io) plugin. Сурагч тоглоом шиг цээж бичгийн дасгал хийж, Монгол бичгийн картаар суралцаж, алдсан үгээ бүгдийг зөв хариулах хүртэл давтана. Багш ангийнхаа хамгийн их алддаг үгсийг самбараас харна.

AI энэ plugin-д сурагчийн оронд бичдэггүй, зөвхөн алдааг тайлбарладаг. Үг зөв эсэхийг эхлээд Монгол хэлний толь бичиг шийднэ, Gemma 4 зөвхөн нэмж тайлбарлана.

## Асуудал ба шийдэл

Сурагчид эсээгээ AI-аар бичүүлдэг болсон тул AI-detection үр дүнгүй болсон. Багш нар хүүхдийн бодит зөв бичгийн мэдлэгийг шалгах хэрэгсэлгүй. Цээж бичиг цаасан дээр явагддаг, засахад багшийн цаг их ордог, алдсан үг дээрээ давтан ажиллах систем байхгүй. Монгол бичгийг сурах сонирхол татахуйц, интерактив хэрэгсэл ч дутмаг.

**Зорилтот хэрэглэгч:** ЕБС-ийн сурагчид (бага, дунд анги), Монгол хэлний багш нар, сургалтын төвүүд.

**Шийдэл:** AI-г хориглохын оронд хүүхдийн мэдлэгийг өөрийг нь хөгжүүлнэ. Сурагч сонсож, сонгож, алдаагаа олж, давтана. Сурагч бүрийн алдсан үгс хадгалагдаж, бүгдийг зөв хариулах хүртэл буцаж гарна. Багш ангийн түгээмэл алдааг нэг дор харна.

## Үндсэн функцүүд

### Дасгал

| Функц | Тайлбар |
|---|---|
| Интерактив онлайн цээж бичиг | Өгүүлбэрийг дуудлагаар сонсоно (waveform анимац, удаан унших горимтой). Зөв бичигдсэн үгийг сонгоно. |
| Spot & Circle the Mistake | Өгүүлбэр дэх алдаатай үг дээр дарахад гараар зурсан мэт дугуйлагдаж, зөв хэлбэр нь гарна. |
| Шууд хариу | Хариулт бүрийн дараа дүрмийн тайлбар гарна. Зөв бол confetti ба дуу, буруу бол зөөлөн shake. |
| Mistake Review Mode | Алдсан үг бүр дүрмийн сануулгатай буцаж гарна. Бүгдийг зөв хариулах хүртэл үргэлжилнэ (100% бататгал). |

### Сурах модулиуд

| Модуль | Тайлбар |
|---|---|
| A. Монгол бичиг | Эхлээд үсгийн байрлалын хэлбэр (үгийн эхэнд, дунд, адагт: титэм, шүд, сүүл) ба зүй тогтлыг таниулна. Дараа нь босоо бичиг ба галигийг харуулж, 4 кирилл хувилбараас сонгуулах эсвэл кириллээр бичүүлнэ. Хариулт бүрийн дараа галиг кирилл болж хувирах тайлбар гарна (`mongɣol` → Монгол, `amidural` → Амьдрал). |
| B. Монгол хэл | Зориуд алдаатай эхээс алдаат үгийг олж дугуйлаад зөв хэлбэрийг бичнэ (`асуудалтайй`, `байны`, `ирэсэн` гэх мэт). Толь бичгээр хатуу (zero-tolerance) шалгаж, дүрэм бүрийн тайлбар өгнө. Мөн цээж бичиг, текст шалгах (JSON тайлан), алдаан дээрээ ажиллах дасгал багтана. |
| C. Уран зохиол | Зөвхөн уран зохиолын эх (Д.Нацагдорж, Б.Явуухулан, С.Эрдэнэ, Т.Галсан гэх мэт, зүйр цэцэн үггүй). Сурагч гол санааг өөрийн үгээр бичихэд утгын тохирлын оноо (0-100%), орхигдсон санаа, сэдвээс хазайлт, зөв бичгийн засвар гарна. Зохиогчийн эрхийн улмаас эх текст багцлагдаагүй. Багш сурах бичгээс хуулж оруулж, Gemma 4 гол санааг санал болгоно. |

## AI хэрхэн ашиглагддаг

Үндсэн зарчим: **AI тайлбарлана, сурагчийн оронд бичихгүй.** Үг зөв, буруу эсэхийг AI дангаараа хэзээ ч шийддэггүй. Эцсийн шийдвэрийг үргэлж толь бичиг гаргана.

### Ашигласан моделиуд

| Модел | Хөгжүүлэгч | Төрөл | Хаана ажилладаг |
|---|---|---|---|
| **Gemma 4** (`gemma-4-26b-a4b-it`) | Google DeepMind | Нээлттэй жинтэй LLM, 26B параметр, Mixture-of-Experts (A4B), instruction-tuned | Gemini API (`generateContent`), сервер дээрээс |
| **Chimege TTS** | Chimege (Монгол) | Монгол хэлний мэдрэлийн сүлжээт яриа нийлэгжүүлэгч | `api.chimege.com/v1.2/synthesize`, сервер дээрээс |
| Hunspell + `dictionary-mn` | LibreOffice / wooorm | AI биш, дүрэмд суурилсан толь бичиг (үр дүн үргэлж ижил) | WebAssembly (`hunspell-asm`), сервер дээр |

### Модуль бүрт AI хаана ажилладаг

| Модуль | Хэсэг | AI | Юу хийдэг |
|---|---|---|---|
| A. Монгол бичиг | Байрлалын хэлбэр, галиг → кирилл | **AI-гүй** | Галиг, кирилл, байрлалын хэлбэрийг гараар бэлдсэн өгөгдлөөс авна. Хариуг толь бичиг ба жигнэсэн Levenshtein-ээр шалгаж, алдааны төрлийг тодорхойлно. |
| A. Монгол бичиг | «Сонсох» товч | Chimege TTS | Зөв үгийг Монгол дуудлагаар уншина (заавал биш). |
| B. Монгол хэл | Алдаа олох | **AI-гүй** | Эх, алдаа, дүрмийн тайлбарыг урьдчилан бэлдэж, толь бичгээр баталгаажуулсан (алдаатай үгийг толь бичиг татгалзаж, бусдыг хүлээн авсан). Тиймээс оноо үргэлж ижил гарна. |
| B. Монгол хэл | Цээж бичиг | Chimege TTS | Өгүүлбэрийг уншина. Chimege ажиллахгүй бол browser-ийн дуу хоолой руу шилжинэ. |
| B. Монгол хэл | Текст шалгах (`educationAiCheck`) | Gemma 4 + толь бичиг | Үг бүрийг шалгаж JSON тайлан гаргана (доорх «Хатуу горим»-ыг үз). |
| B. Монгол хэл | Хичээл үүсгэгч (`educationLessonGenerate`) | Gemma 4 | Багшийн сэдвээр `pick` ба `spot` өгүүлбэр, буруу хэлбэр, дүрэм зохионо. Сервер өгүүлбэр бүрийг шалгаж (зорилтот үг яг 1 удаа орсон, буруу хэлбэр байгаа эсэх), хүчинтэйг нь л хадгална. |
| C. Уран зохиол | Утгын тохирлын оноо (`educationLiteratureAnswer`) | Gemma 4 | Сурагчийн гол санааг эх, жишиг утга, гол санаануудтай харьцуулж `score` (0-100), `matched_points`, `missed_points`, `deviations`, `feedback_mn` гаргана. Мөн бичвэрийг B модулийн хатуу шалгагчаар давхар шалгана. |
| C. Уран зохиол | Багшид туслах (`educationLiteratureSuggest`) | Gemma 4 | Багшийн хуулж оруулсан эхийн сэдэв ба гол санааг санал болгоно. Багш засаж батална. Gemma эх текст үүсгэдэггүй. |
| C. Уран зохиол | «Сонсох» товч | Chimege TTS | Эхийг мөр мөрөөр уншина (заавал биш). |

### Хатуу горим (Strict Mode)

Текст шалгахдаа эхлээд толь бичиг, дараа нь Gemma 4 ажиллана.

```
 сурагчийн текст
      |
      v
 1. Hunspell (Монгол толь бичиг, WebAssembly)
    Үг бүр зөв эсэхийг шийднэ. Толь бичигт байхгүй үг is_correct:false
    болно, AI үүнийг хэзээ ч өөрчилж чадахгүй.
      |
      v
 2. Gemma 4
    Толь бичигт байгаа ч буруу хэрэглэсэн үгийг олж, тайлбар нэмнэ
    (цас/цаас, «цагаан сар» -> «Цагаан сар»).
      |
      v
 3. Жигнэсэн Levenshtein
    Hunspell-ийн саналуудаас хамгийн ойрыг сонгоно.
```

1. **Толь бичиг шийднэ.** [dictionary-mn](https://github.com/wooorm/dictionaries/tree/main/dictionaries/mn) (LibreOffice-ийн Монгол Hunspell толь бичиг) WebAssembly-ээр (`hunspell-asm`) сервер дээр ажиллана. Толь бичигт байхгүй үг үргэлж `is_correct: false` болно. Жишээ нь `асуудалтайй` → `асуудалтай` (Typo), `байны` → `байна` (Spelling), `хичээлдаа` → `хичээлдээ` (Vowel Harmony).
2. **Gemma 4 нэмнэ, дарахгүй.** Gemma-ийн засварыг зөвхөн засварласан үг нь толь бичигт байвал хүлээн авна. Толь бичигт байгаа ч буруу хэрэглэсэн үг (цас/цаас), том жижиг үсгийн алдааг Gemma олно. Монгол хэлээрх тайлбарыг (`explanation_mn`) Gemma бичнэ.
3. **Саналыг эрэмбэлнэ.** Hunspell-ийн саналуудаас эгшиг ба эгшгийн солилт, давхардсан үсэг хасахыг хямд үнэлдэг жигнэсэн Levenshtein-ээр хамгийн ойрыг сонгоно.

Үг бүрийн хариу дараах бүтэцтэй JSON байна:

```json
{ "original_word": "байны", "is_correct": false, "corrected_word": "байна",
  "error_type": "Spelling", "explanation_mn": "..." }
```

`error_type` нь `Spelling`, `Vowel Harmony`, `Typo`, `None`-ийн аль нэг.

### Найдвартай ажиллуулах арга

- **Хатуу JSON.** System prompt бүр JSON бүтцийг шаардана. `temperature: 0.3` тохиргоотой. Хариуг **Zod** схемээр шалгах бөгөөд бүтэц буруу ирвэл Gemma-ийн хариуг хаяна.
- **Офлайн горим.** Түлхүүр байхгүй эсвэл Gemma алдаа өгвөл програм зогсохгүй:
  - текст шалгалт толь бичиг ба хичээлүүдийн түгээмэл алдаагаар үргэлжилнэ;
  - уран зохиолын оноо үгийн язгуурын давхцлаар тооцогдоно;
  - хариу бүрт `source: "gemma"` эсвэл `"offline"` гэж тэмдэглэгдэнэ.
- **Нууцлал.** `GEMINI_API_KEY`, `CHIMEGE_TOKEN` зөвхөн сервер дээр (`.env`) хадгалагдаж, browser руу хэзээ ч явахгүй.
- **Зохиогчийн эрх.** Уран зохиолын эхийг AI үүсгэдэггүй, програмд багцлагдаагүй. Зөвхөн багш оруулна.
- Моделийг `GEMMA_MODEL` хувьсагчаар солино.

### Chimege (Монгол TTS)

Зөвхөн нэмэлт «Сонсох» товчинд ашиглана. Карт, цээж бичгийн өгүүлбэр, уран зохиолын эхийг Монгол дуу хоолойгоор (speed 0.95) уншина. Текст бүрийн аудиог серверт кэшлэнэ. Түлхүүр тохируулаагүй бол browser-ийн дуу хоолой руу автоматаар шилжинэ. Түлхүүрээ шалгах команд:

```bash
pnpm --filter education_api chimege:check
```

## erxes интеграц

Энэ plugin нь erxes monorepo-оос гадуур амьдардаг жинхэнэ erxes plugin бөгөөд `create-erxes-plugin` (platform stack)-ээр үүсгэгдсэн.

```
 Browser --> erxes core-ui (:3001) --loads--> education_ui remoteEntry.js (:3099)
                                              (Module Federation: React, Apollo,
                                               router, erxes-ui нь host-ийн singleton)

 erxes gateway (:4000, Apollo Router) --federates--> core-api (:3300)
                                      \-------------> education_api (:3399)
                                                      Redis-д өөрийгөө бүртгүүлнэ
                                                            |
                                                            v
                                               MongoDB (tenant-д хамаарах модель)
```

| Асуудал | Хэрхэн шийдсэн |
|---|---|
| Service discovery | `erxes-api-shared`-ийн `startPlugin()` бүртгэлийг Redis-д бичнэ (`erxes-service-education`, `UI_ENTRY_URL`). Gateway болон core-api `ENABLED_PLUGINS`-д `education` байвал plugin-ийг автоматаар олно. |
| GraphQL Federation | API нь `Education*` төрөл, `education*` query ба mutation бүхий subgraph. erxes gateway үүнийг нэг supergraph болгоно (`educationMe`, `educationSubmitAttempt`, `educationAiCheck`, `educationClassOverview` гэх мэт). |
| Хэрэглэгч ба эрх | Сурагч, багш нь erxes team member. Нэвтэрсэн хэрэглэгч gateway-аас `context.user` болж ирнэ. Эрх нь erxes-ийн permission системээр: `educationPractice`, `educationTeach` үйлдлүүд, мөн бэлэн бүлгүүд Education - Students, Education - Teachers (Settings -> Permissions). |
| Tenant isolation | Бүх өгөгдөл `generateModels(subdomain)`-ээр тухайн байгууллагын MongoDB-д хадгалагдана: `education_lessons`, `education_cards`, `education_progress`, `education_attempts`, `education_literature`. |
| UI | erxes-ийн `AppLayout`, sidebar, `PageHeader`, favorites, toast, dark mode зэрэг host-ийн design system-ийг ашиглана. Plugin-ийн өөрийн загвар `edu-` угтвартай тул host-д нөлөөлөхгүй. |

Дэлгэрэнгүй: [docs/erxes-integration.md](docs/erxes-integration.md).

## Суулгах, ажиллуулах

### Шаардлага

- Ажиллаж буй erxes (core-api, gateway, core-ui). Заавар: [erxes Local Setup](https://erxes.io/docs/local-setup). Windows дээр WSL2 ашиглана.
- MongoDB replica set (MongoDB Atlas ч болно) ба Redis
- Node.js 22
- pnpm 9.12.3

### 1. Татаж аваад суулгах

```bash
git clone https://github.com/lukuni/erxes-education-plugin.git education
cd education
pnpm install
cp .env.example .env
```

### 2. `.env` тохируулах

erxes-тэй ижил MongoDB, Redis-ийг зааж өгнө.

```bash
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
MONGO_URL=mongodb://127.0.0.1:27017/erxes?replicaSet=rs0&directConnection=true
UI_ENTRY_URL=http://localhost:3099/remoteEntry.js

# Заавал биш. Эдгээргүйгээр ч үндсэн функцүүд ажиллана.
CHIMEGE_TOKEN=
GEMINI_API_KEY=
GEMMA_MODEL=gemma-4-26b-a4b-it
```

`GEMINI_API_KEY`-г https://aistudio.google.com/apikey хаягаас авна.

### 3. Plugin-ийг ажиллуулах

Хоёр терминал нээж, тус бүрт нэг командыг ажиллуулна.

```bash
pnpm run dev:api   # :3399, erxes gateway-д бүртгэгдэнэ
pnpm run dev:ui    # :3099, remoteEntry.js-ийг үйлчилнэ
```

### 4. erxes талд идэвхжүүлах

erxes-ийн `.env` дэх `ENABLED_PLUGINS` мөрийг дараах байдлаар тохируулна:

```bash
ENABLED_PLUGINS=education
```

> **Анхаар:** `ENABLED_PLUGINS=` гэж хоосон үлдээж болохгүй. Хоосон утга нэргүй plugin болж хувирдаг тул gateway `Waiting for plugin  to join service discovery` гэж үүрд хүлээж, порт 4000 нээгдэхгүй.

Үйлчилгээнүүдийг дараах дарааллаар асаана. Gateway асахдаа API-уудын схемийг татдаг тул **хамгийн сүүлд** асаана.

1. MongoDB, Redis
2. erxes core-api (:3300)
3. education API (`pnpm run dev:api`, :3399)
4. erxes gateway (:4000)
5. education UI (`pnpm run dev:ui`, :3099) ба erxes core-ui (:3001)

### 5. Нээх

http://localhost:3001/education

Анхны хүсэлтээр жишээ хичээл, картууд автоматаар үүснэ. erxes-ийн owner бүх эрхтэй. Бусад хэрэглэгчийг Settings -> Permissions хэсэгт Education - Students эсвэл Education - Teachers бүлэгт нэмнэ.

### API түлхүүргүй үед юу ажиллах вэ

| Функц | Түлхүүргүй | Түлхүүртэй |
|---|---|---|
| Цээж бичиг, Spot & Circle, давтлага, Монгол бичгийн карт | Бүрэн ажиллана | Бүрэн ажиллана |
| Хатуу шалгалт (Hunspell толь бичиг) | Бүрэн ажиллана | Бүрэн ажиллана |
| AI редактор | Офлайн горим | Gemma 4 тайлбар, утгын алдаа нэмэгдэнэ |
| ЭЕШ ба уран зохиолын оноо | Үгийн язгуурын давхцал | Gemma 4 утгын оноо |
| Хичээл үүсгэгч | Ажиллахгүй (`GEMINI_API_KEY` шаардана) | Ажиллана |
| Дуу | Browser-ийн дуу хоолой | Chimege Монгол дуу хоолой |

| UI | React 18, Module Federation (Rspack), Apollo Client, `@erxes/ui`, `@erxes/ui-modules`, Tailwind CSS 4 (угтвартай), GraphQL Codegen |

| Фонт | Noto Sans Mongolian (босоо Монгол бичиг) |

## Хязгаарлалт ба цаашдын төлөвлөгөө

### Одоогийн хязгаарлалт

- Сурагч нь erxes team member бөгөөд нэвтэрч орно. Хариултыг шалгах нь хурдан хариу өгөхийн тулд browser дээр явагдаж, сервер нь хичээлийн өгөгдлөөр алдааг бүртгэнэ.
- Төхөөрөмж дээр Монгол дуу хоолой суугаагүй бол browser-ийн дуудлага ойролцоо байна.
- Жишээ үг, дүрмийг Монгол хэлний багшаар хянуулах шаардлагатай.
- Зохиогчийн эрхийн улмаас уран зохиолын эх текст багцлагдаагүй. Багш өөрөө оруулна.
- Хичээл үүсгэгч нь Gemini API түлхүүр шаардана.

### Цаашид хийх

- erxes Contacts ба Client Portal-оор сурагч, эцэг эхэд зориулсан widget (team member биш)
- erxes Automations ба Notifications: streak тасрах гэж байхад сануулга, багшид долоо хоногийн тайлан
- Гараар бичих цээж бичиг (сонсоод бүтэн өгүүлбэр бичих) ба Gemma-ийн дүгнэлт
- Монгол бичгийн бичлэгийн дасгал (зурж бичих), Gemma-аар галиг ба кирилл хөрвүүлэх
- Ангиудаар бүлэглэх, leaderboard, ангийн тэмцээн

## Ашигласан AI хэрэгслүүд

- Бүтээгдэхүүн доторх AI: Gemma 4 (Gemini API) нь тайлбар, хичээл үүсгэх, утгын оноонд ашиглагдана. Chimege нь Монгол TTS-д ашиглагдана. AI-ийн бүх хариуг сервер дээр шалгасны дараа харуулж эсвэл хадгална.
- Хөгжүүлэлтэд ашигласан AI хэрэгслүүд (доорх хүснэгт).

### Хөгжүүлэлтэд AI хаана ашиглагдсан

| Хэрэгсэл | Ашигласан хэсэг | Тайлбар |
|---|---|---|
| Claude (Anthropic, Claude Opus) | API (`api/`) | GraphQL schema, Hunspell холболт, Gemma ба Chimege client, оноо тооцох логик |
| Claude (Anthropic, Claude Opus) | UI (`ui/`) | Хуудас, компонент, анимац, загвар |
| Claude | erxes интеграц | Plugin-ийг erxes gateway, core-ui-тай холбож ажиллуулах, алдааг оношлох |
| Claude | Агуулга | Жишээ хичээл, үг, дүрмийн тайлбар, картууд |
| Gemini | Агуулга | Жишээ хичээл, үг, дүрмийн тайлбар, картууд |
| Claude | README | README-ийн бичвэрийг боловсруулсан |

Санаа, модулийн бүтэц, Монгол хэлний агуулгын шийдвэрийг баг гаргасан. Алдаа олох эхийн алдаатай болон зөв үг бүрийг толь бичгээр автоматаар шалгасан. AI-аар үүсгэсэн агуулгыг Монгол хэлний багшаар хянуулах шаардлагатай (хязгаарлалтын хэсгийг үз).

### Ашигласан нээлттэй эхийн код

- erxes-ийн shared сангууд ба UI багц, `hunspell-asm`, `dictionary-mn`. Plugin-ийн суурийг `create-erxes-plugin`-ээр үүсгэсэн.
